Global Seismic Trends Analysis

Project Overview

This project analyzes global earthquake (seismic) data to uncover trends, patterns, and insights related to earthquake frequency, magnitude, location, and time.
The dataset is sourced from the USGS Earthquake API, and the project includes data processing, analysis, database integration, and visualization using Python.



Objectives

Analyze global earthquake trends over multiple years

Identify regions with high seismic activity

Study magnitude distribution and time-based patterns

Build a clean and interactive data visualization dashboard

Store and query earthquake data using SQL databases


Technologies Used

Python

Pandas & NumPy

Streamlit (for dashboard)

MySQL 

USGS Earthquake API

Git & GitHub


Install Dependencies

pip install -r requirements.txt


For Data Retrival 

python data_retrieval.py 

For Data Import to SQL 

python data_import_sql.py 


Run the Streamlit Dashboard

python -m streamlit run dashboard/app.py
